# Terrestream brand assets

Official Terrestream artwork: the 500×500 leaf and 256×52 light/dark
wordmarks from the public website. Export metadata has been removed; image and
color data are unchanged. `logo.png` is dark text for light backgrounds;
`dark_logo.png` is light text for dark backgrounds. The green leaf works on both.
Terrestream is a service mark of Aerodyne Inc. Copyright permissions for this
artwork follow the project's Apache 2.0 license; section 6 reserves mark rights.
No permission to imply endorsement or certification is granted.

These images are served locally by Home Assistant 2026.3 and later. For Core,
submit the artwork to home-assistant/brands and omit this directory from Core.
